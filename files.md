### 1. Визуальная структура проекта
```
app/src/main/java/com/example/tvoya_zhdulya/
├── api/                    # Слой сетевого взаимодействия (Retrofit)
│   ├── ApiClient.java      # Настройка клиента и базового URL
│   ├── CatApiService.java  # Интерфейс запросов к внешнему API котиков
│   └── CatResponse.java    # Модель ответа от API
├── data/                   # Слой работы с данными (Room DB)
│   ├── AppDatabase.java    # Основной класс БД (Singleton)
│   ├── Converters.java     # Конвертеры типов (Date <-> String)
│   ├── Person.java         # Сущность: профиль ожидаемого человека
│   ├── PersonDao.java      # Методы доступа к данным профилей
│   ├── JournalEntry.java   # Сущность: записи в дневнике и события
│   ├── JournalDao.java     # Методы доступа к записям
│   ├── MoodEntry.java      # Сущность: история настроения
│   └── MoodDao.java        # Методы доступа к данным настроения
├── ui/                     # Слой интерфейса (MVVM)
│   ├── MainViewModel.java  # Бизнес-логика, работа с LiveData и API
│   ├── MainActivity.java   # Экран календаря и дневника конкретного человека
│   └── PersonsActivity.java # Главный экран со списком всех людей
└── NotificationReceiver.java # Обработчик системных уведомлений

```


### 2. Описание ключевых модулей


* **Пакет `data**`: Реализует локальное хранение данных с использованием библиотеки Room.
* `Person.java` хранит основные данные (имя, дата освобождения).
* `JournalEntry.java` отвечает за хранение заметок и флагов «свидание»/«передача».


* **Пакет `ui**`: Использует паттерн MVVM.
* `MainViewModel.java` является связующим звеном: она запрашивает данные из БД и API, обрабатывает их и предоставляет `LiveData` для UI-компонентов.
* `MainActivity.java` отвечает за визуализацию календаря и обработку кликов пользователя по датам.


* **Пакет `api**`: Отвечает за интеграцию с внешним миром. Через Retrofit приложение обращается к API, чтобы получить случайный развлекательный контент (картинки котиков), что помогает снизить уровень стресса пользователя.
* **`NotificationReceiver`**: Позволяет приложению взаимодействовать с ОС Android для вывода напоминаний, даже если само приложение закрыто.

---

### 3. Ресурсы (Layouts)

Также полезно упомянуть ключевые файлы разметки в `res/layout/`:

* `activity_persons.xml`: Главный экран со списком.
* `activity_main.xml`: Экран календаря с интегрированными элементами для котиков и цитат.
* `dialog_add_person.xml`: Форма ввода данных нового человека.
