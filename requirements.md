### Описание функциональных требований

Выделяются следующие функциональные требования:

* **Управление списком людей:** Пользователь должен иметь возможность добавлять новых людей (имя, дата освобождения), просматривать их список и удалять записи.
* **Расчет времени ожидания:** Система должна автоматически вычислять количество дней, оставшихся до указанной даты релиза для каждого человека.
* **Ведение календаря настроения:** Пользователь может выбирать один из четырех типов настроения для текущей даты, что отображается цветом в календаре.
* **Журнал заметок:** Приложение позволяет сохранять и редактировать текстовые мысли пользователя, привязанные к конкретной дате.
* **Планирование событий:** Пользователь может отмечать дни «Встреч» или «Передачек» в будущем.
* **Система уведомлений:** Приложение должно отправлять локальное уведомление за день до запланированного события.
* **Интерактивный контент:** Получение случайных «антистресс» изображений котиков и вдохновляющих цитат через внешние API.

### 2. Текстовые сценарии 

#### Сценарий 1: Добавление нового человека

1. **Действие:** Пользователь нажимает кнопку «+ Добавить человека» на главном экране.
2. **Система:** Открывает диалоговое окно с полями для ввода имени и выбора даты в DatePicker.
3. **Действие:** Пользователь вводит данные и подтверждает добавление.
4. **Система:** Сохраняет данные в БД Room и обновляет список, отображая имя и количество оставшихся дней.

#### Сценарий 2: Фиксация настроения в календаре

1. **Действие:** Пользователь выбирает человека из списка и нажимает на текущую дату в календаре.
2. **Система:** Отображает список доступных настроений.
3. **Действие:** Пользователь выбирает вариант (например, «Люблю»).
4. **Система:** Окрашивает ячейку даты в календаре в соответствующий цвет (розовый) и сохраняет выбор в базе.

#### Сценарий 3: Планирование события

1. **Действие:** Пользователь нажимает «Запланировать встречу / передачку».
2. **Действие:** Выбирает тип события и дату в будущем.
3. **Система:** Добавляет метку `[В]` или `[П]` к дате в календаре и планирует системное уведомление на 10:00 утра предыдущего дня.
